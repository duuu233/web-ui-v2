④ 确认

将覆盖 3 台设备的 FACTORY / SET / NO_WIFI 共 3 个槽位（在线 3 台，离线 0 台）。 离线设备进入待补发，7 天内上线自动补，超期失效。覆盖后无法自动恢复。
