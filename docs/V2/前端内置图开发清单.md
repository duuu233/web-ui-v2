# 内置图管理 · 前端开发清单（定稿）

> 2026-11-13　·　后端已实现，可直接按本文联调
> 配套原型：[内置图后台原型.html](原型/内置图后台原型.html)

**核心规则：下发清单必须从 `FACTORY` 开始连续。**
只更新 FACTORY 就只发 FACTORY；要更新 NO_WIFI，必须同时带上 FACTORY、SET。
槽位中间缺一个，后面的都不能推。

---

## 1. 通用约定

| 项 | 值 |
|---|---|
| 前缀 | `/admin/intimg` |
| 鉴权 | Header `X-Internal-Token`（当前线上未启用校验） |
| 响应体 | `{ "code": 0, "msg": "ok", "data": ... }`，`code=0` 成功 |
| 分页参数 | `page` 从 1 开始；`size` 默认 20、最大 100 |
| 分页返回 | `{ "total": 123, "page": 1, "size": 20, "list": [...] }` |
| 时间 | `yyyy-MM-dd HH:mm:ss`（Asia/Shanghai），服务端已格式化 |
| 设备号 | `deviceNo`，12 位十六进制、**不带冒号** |

除分页接口外，`data` 均为对象或数组；失败时 `data=null` 且 `code≠0`。

## 2. 页面与元素

### 2.1 槽位管理

- 产品切换：只展示**版本类型 = wifi** 的产品；卡片显示尺寸型号、屏幕方向、渲染模式、已配置数 `x/6`。
- 每个产品固定 6 个槽位，顺序固定（见 §5.1）。
- 上传：
  1. 图片宽高必须**等于**产品「尺寸(cm)」（值如 `1200*1600`，单位像素）；
  2. 图片内容方向必须已是最终方向（横向/竖向旋转度数由前端上传前应用）；
  3. 同时带上产品渲染参数：`renderMode` / `orientation` / `canvasWidth` / `canvasHeight`；
  4. 成功后返回槽位（`status=READY`，`version+1`）。
- 槽位状态：`READY` 已配置 / `RENDERING_DISABLED` 未配置。
- 「重新渲染」：源图不变、按当前参数重生成，版本 +1。

### 2.2 设备内置图状态

- 筛选：产品、版本状态、在线、登记状态、设备号搜索；分页。**没有槽位筛选**。
- 列：设备号、登记状态、在线、已推送（`pushedSlots/6`）、落后槽位数、可选中状态。
- 设备整体 `state`：6 个槽位全部最新 → `LATEST`；没有任何槽位推送过 → `NOT_PUSHED`；其余 → `OUTDATED`。
- `selectable=false` 时禁用复选框，展示锁任务号与到期时间。
- 「全选当前筛选结果」用 `selectAll + filter`，不要翻页收集。

### 2.3 新建推送任务

1. 选产品；
2. **选目标槽位**（可多选）：服务端自动补齐 FACTORY 起的前缀，页面需实时展示「实际下发清单」；
   - 超过「连续已配置前缀」的槽位不可选，提示需先配置哪个槽位；
3. 选设备（筛选同 2.2）；
4. 确认：写明**实际下发的槽位清单**，覆盖 N 台（在线 X / 离线 Y）；离线进入待补发，7 天内上线自动补。

提交后立即返回 `taskNo`，页面可离开。

### 2.4 任务列表 / 详情

- 列表列：任务号、产品、**目标槽位**、**实际下发清单**（`slotVersionText`）、总数、成功、已下发、失败、待补发、已取消、状态、时间。
- 详情 Tab：全部 / 待补发 / 已下发 / 成功 / 失败 / 已失效 / 已取消。
- 批量：移除所选设备（释放锁）、重发失败设备（按原任务的目标槽位重发）。

### 2.5 设备锁排查

- 列：设备号、产品、在线、锁持有者、到期时间、强制释放。
- 锁来源：离线待补发（7 天）、已下发后 2 分钟。

## 4. 接口明细

### 4.1 槽位汇总

`GET /admin/intimg/slots/summary?productIds=p1,p2`

| 参数 | 必填 | 说明 |
|---|---|---|
| `productIds` | 否 | 逗号分隔；不传返回空数组 |

返回字段：`productId`、`configured`（已上传数 0~6）、`total`（固定 6）、`ready`（READY 数）。

```json
{ "code": 0, "msg": "ok",
  "data": [ { "productId": "709", "configured": 6, "total": 6, "ready": 6 } ] }
```

### 4.2 槽位列表

`GET /admin/intimg/slots?productId=709`

返回固定 6 个元素，顺序同 §5.1。

| 字段 | 类型 | 说明 |
|---|---|---|
| slotKey | string | 槽位 key |
| slotName | string | 中文名 |
| sourceUrl | string\|null | 源图 URL；未配置为 null |
| previewUrl | string\|null | 预览 URL（当前与 `sourceUrl` 相同） |
| canvasWidth / canvasHeight | int\|null | 画布尺寸 |
| version | int | 版本号；未配置为 0 |
| status | string | `READY` / `RENDERING_DISABLED` |
| updatedBy / updatedAt | string\|null | 最后操作人 / 时间 |

### 4.3 上传 / 替换（上传即渲染）

`POST /admin/intimg/slots/{productId}/{slotKey}/image`　`multipart/form-data`

| 参数 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `file` | 是 | file | PNG/JPG，宽高必须等于 `canvasWidth × canvasHeight` |
| `renderMode` | 否 | string | `esp32`（默认）/ `fpga16` |
| `orientation` | 否 | string | `PORTRAIT`（默认）/ `LANDSCAPE` |
| `canvasWidth` | 否 | int | 默认 1200，必须 > 0 |
| `canvasHeight` | 否 | int | 默认 1600，必须 > 0 |

返回单个槽位对象（同 4.2），`status=READY`、`version+1`。

错误：尺寸不符 `4000`；`renderMode`/`orientation` 非法 `4000`；渲染失败或产物大小不符 `5001`；OSS 失败 `5002`。

### 4.4 重新渲染

`POST /admin/intimg/slots/{productId}/{slotKey}/render`（无请求体）

| 字段 | 类型 | 说明 |
|---|---|---|
| status | string | `READY` |
| version | int | 重渲染后的版本 |
| binSize | long | 产物字节数 |
| renderedAt | string | 渲染时间 |

错误：槽位无源图 `4000`。

### 4.5 设备内置图状态

`GET /admin/intimg/devices?productId=&versionState=&online=&registered=&keyword=&page=&size=`

| 参数 | 必填 | 说明 |
|---|---|---|
| `productId` | 是 | 产品 ID |
| `versionState` | 否 | `LATEST` / `OUTDATED` / `NOT_PUSHED`（按设备整体状态筛选） |
| `online` | 否 | `true` / `false` |
| `registered` | 否 | `true` 已激活 / `false` 未激活 |
| `keyword` | 否 | 设备号模糊匹配（不区分大小写） |

返回 `Page<DeviceItem>`：

| 字段 | 类型 | 说明 |
|---|---|---|
| deviceNo | string | 设备号 |
| remark | string\|null | 备注；当前恒 null |
| registered | bool | 是否已激活（当前恒 true） |
| online | bool | 当前在线 |
| state | string | 设备整体状态：`LATEST` / `OUTDATED` / `NOT_PUSHED` |
| pushedSlots | int | 已是最新的槽位数（0~6） |
| outdatedSlots | int | 落后槽位数（0~6） |
| slots | array | 固定 6 个槽位明细，顺序同 §5.1 |
| slots[].slotKey / slotName | string | 槽位 key / 中文名 |
| slots[].state | string | 该槽位状态 |
| slots[].currentVersion | int\|null | 设备已成功的该槽位版本；从未推送为 null |
| slots[].latestVersion | int | 该槽位当前版本；未配置为 0 |
| locked | bool | 是否被任务占用 |
| lockTaskNo / lockExpireAt | string\|null | 锁信息 |
| selectable | bool | **以它为准禁用复选框** |

```json
{ "code": 0, "msg": "ok",
  "data": { "total": 4, "page": 1, "size": 20,
    "list": [ {
      "deviceNo": "3844BE2E5220", "remark": null, "registered": true, "online": true,
      "state": "OUTDATED", "pushedSlots": 5, "outdatedSlots": 1,
      "slots": [
        { "slotKey": "FACTORY", "slotName": "出厂图", "state": "OUTDATED",
          "currentVersion": 3, "latestVersion": 4 },
        { "slotKey": "SET", "slotName": "设置图", "state": "LATEST",
          "currentVersion": 1, "latestVersion": 1 }
      ],
      "locked": false, "lockTaskNo": null, "lockExpireAt": null, "selectable": true
    } ] } }
```

> 示例为节选，实际 `slots` 固定 6 个元素。

### 4.6 新建推送任务

`POST /admin/intimg/tasks`　`application/json`

| 字段 | 必填 | 说明 |
|---|---|---|
| `productId` | 是 | 产品 ID |
| `slotKeys` | 是 | **目标槽位**数组（运营勾选的槽位），至少 1 个；服务端自动补齐 FACTORY 起的前缀 |
| `deviceNos` | 否 | 指定设备；与 `selectAll` 二选一 |
| `selectAll` | 否 | `true` 表示按 `filter` 全选 |
| `filter.versionState` | 否 | 同 4.5 |
| `filter.online` | 否 | 同 4.5 |
| `filter.registered` | 否 | 同 4.5 |

```json
// ① 指定设备，只更新 NO_WIFI（实际清单为 FACTORY + SET + NO_WIFI）
{ "productId": "709", "slotKeys": ["NO_WIFI"], "deviceNos": ["3844BE2E5220"] }

// ② 全选筛选结果
{ "productId": "709", "slotKeys": ["FACTORY"], "selectAll": true,
  "filter": { "versionState": "NOT_PUSHED", "online": true } }
```

| 返回字段 | 类型 | 说明 |
|---|---|---|
| taskNo | string | 任务号 |
| total | int | 本次纳入的设备数（含被占用跳过的） |
| status | string | 创建瞬间的状态，通常 `RUNNING`；以查询结果为准 |

错误 `4000`：未传 `slotKeys`、无匹配设备、目标槽位之前有未配置槽位（如「槽位「设置图」未配置，无法更新「无 WiFi 提示」」）。

### 4.7 任务列表 / 详情

`GET /admin/intimg/tasks?productId=&status=&page=&size=`
`GET /admin/intimg/tasks/{taskNo}`

| 字段 | 类型 | 说明 |
|---|---|---|
| taskNo | string | 任务号 |
| productId | string | 产品 ID |
| targetSlots | array | 运营勾选的目标槽位 |
| slotVersions | object | 实际下发清单的版本快照，如 `{"FACTORY":3,"SET":1,"NO_WIFI":1}` |
| slotVersionText | string | 展示文案，如 `F:3 S:1 N:1` |
| total | int | 设备总数 |
| success | int | 设备回 113/0/1 的数量 |
| sent | int | 已下发（回 106），未拿到最终结果 |
| failed | int | `FAILED` + `EXPIRED` + `SKIPPED_BUSY` |
| pending | int | 待补发（设备离线） |
| canceled | int | 已取消 |
| status | string | `RUNNING` / `DONE` / `CANCELED` |
| createdBy / createdAt | string | 创建人 / 时间 |
| finishedAt | string\|null | 完成时间；还有待补发时为 null |

> 五个计数相加 = `total`。

### 4.8 任务明细

`GET /admin/intimg/tasks/{taskNo}/items?status=&page=&size=`

| 字段 | 类型 | 说明 |
|---|---|---|
| deviceNo | string | 设备号 |
| online | bool | 当前在线 |
| status | string | 见 §5.3 |
| errorCode | string\|null | 机器可读失败码（如 `PUBLISH_FAILED`、`SLOT_CHANGED`、`SKIPPED_BUSY`、`EXPIRED`、设备返回码） |
| errorMessage | string\|null | 中文说明，可直接展示 |
| lockExpireAt | string\|null | 该设备当前锁到期时间 |
| updatedAt | string | 明细更新时间 |

### 4.9 取消 / 重发

| 接口 | 请求体 | 返回 |
|---|---|---|
| `POST /admin/intimg/tasks/{taskNo}/items/cancel` | `{"deviceNos":["..."]}` | `{ "affected": 1 }` |
| `POST /admin/intimg/tasks/{taskNo}/items/retry` | `{"deviceNos":["..."]}`，可传空 | `{ "taskNo": "...", "total": 1, "status": "RUNNING" }` |

- 取消仅对 `PENDING` / `SENT` 生效，立即释放锁；重复取消 `affected=0`。
- 重发不传设备 → 重发该任务全部 `FAILED`；没有可重发设备 → `4000`。
- 重发生成新任务，沿用原任务的目标槽位（仍按前缀规则展开）。

### 4.10 设备锁

`GET /admin/intimg/locks?deviceNo=&page=&size=`

| 字段 | 类型 | 说明 |
|---|---|---|
| deviceNo | string | 设备号 |
| productId | string\|null | 锁持有任务所属产品 |
| online | bool | 当前在线 |
| taskNo | string | 锁持有任务号 |
| slotKey | string\|null | 历史单槽位任务才有值；新任务恒 null |
| expireAt | string\|null | 锁到期时间 |

`POST /admin/intimg/locks/{deviceNo}/release` → `{ "affected": 1 }`（无锁时 0）。

## 5. 枚举

### 5.1 槽位（固定 6 个，顺序不变）

| slotKey | 中文名 | 用途 |
|---|---|---|
| FACTORY | 出厂图 | 出厂 / 复位后 |
| SET | 设置图 | 进入设置 / 配网 |
| NO_WIFI | 无 WiFi 提示 | 连不上 WiFi |
| LOW_BATTERY | 低电量提示 | 电量低 |
| LOW_POWER_OFF | 低电量关机页 | 低电关机 |
| CONNECTED | 连接页 | 配网中 / 已连接 |

### 5.2 槽位状态

`READY` 已配置 / `RENDERING_DISABLED` 未配置。

### 5.3 明细状态

| status | 前端文案 | 说明 |
|---|---|---|
| `PENDING` | 待补发 | 设备离线，上线后自动补 |
| `SENT` | 已下发 | 设备已回 106，未拿到最终结果 |
| `SUCCESS` | 成功 | 设备回 113/0/1 |
| `FAILED` | 失败 | 下发失败 / 设备返回失败码 |
| `EXPIRED` | 已失效 | 超出 7 天补发窗口 |
| `SKIPPED_BUSY` | 设备忙 | 创建任务时被其它任务占用 |
| `CANCELED` | 已取消 | 运营手动取消 |

### 5.4 版本状态

`LATEST` 最新 / `OUTDATED` 落后或部分未推送 / `NOT_PUSHED` 未推送。

## 6. 错误码

| code | 场景 |
|---|---|
| 0 | 成功 |
| 4000 | 参数错误（缺参 / slotKeys 非法 / 目标槽位之前有未配置槽位 / 图片尺寸不符 / renderMode 或 orientation 非法 / 画布非正数 / 无匹配设备 / 无源图可渲染） |
| 401 | `X-Internal-Token` 不匹配 |
| 4044 | 任务不存在 |
| 5000 | 服务端异常 |
| 5001 | 渲染失败 / 产物大小不符 / 源图拉取失败 |
| 5002 | OSS 上传失败 |

## 7. 交互与实现约束

1. 推送异步，提交后跳任务列表，不等待。
2. 忙设备以 `selectable=false` 为准。
3. 离线可推，进待补发（7 天窗口）。
4. 目标槽位超出「连续已配置前缀」时不可选，并提示需先配置哪个槽位。
5. 覆盖不可逆，确认弹窗必须展示实际下发清单。
6. 上传前先校验尺寸与方向。
7. 同一设备已下发后 **2 分钟内**锁未释放，再推会得到 `SKIPPED_BUSY`。
8. 设备只回 `106`，列表按「已下发」展示，不要写成「成功」。
9. 设备列表的 `remark` 当前恒 null，前端要容错。
10. 任务列表最多返回最近 **500** 条；更早的用任务号直接查详情。
11. 没有「删除槽位」接口；替换即覆盖，版本递增。
12. 设备按需下载：推送后设备只在对应页面拉取所需槽位的 bin，不代表所有槽位立刻生效。
13. bin 生成完全由服务端负责，前端只上传 PNG 并确保尺寸/方向正确。
