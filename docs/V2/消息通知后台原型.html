接口约定（供后端参考）

GET /admin/notification/list?deviceNo=3844BE2E5220&page=1&size=20&lang=zh-CN
Header: X-Internal-Token: <可选，服务端当前不校验>

    "total": 227, "page": 1, "size": 20,

    "list": [
      {
        "id": 764,

        "read": false,          // 后台不使用

      }
    ]
  }
}
  • 参数与返回结构同 App 端 /api/notification/list，后台只需换路径。
  • 返回全部记录，包括 visible=0 的上下线抖动记录；返回里没有 visible 字段，后台不区分。
  • read 固定 false、unreadCount 固定 0、unreadOnly 不生效。
  • 设备离线又快速上线会产生成对的「设备已离线 / 设备已上线」记录，这是 5 分钟抖动抑制的原始数据，App 端已隐藏，后台正常展示即可。
  • 跨域：/admin/** 仅允许 https://badmin.boltfox.cn。
